- สวัสดีครับ ผม ปิติพล ตั้งเจิดจ้า กำลังศึกษาชั้นปีที่ 3 สาขาวิทยาการคอมพิวเตอร์ ที่มหาวิทยาลัยเกษตรศาสตร์ครับ 
จุดเริ่มต้นที่ทำให้ผมสนใจสายงานนี้ มาจากความหลงใหลในเกมและการ Mod เกมมาตั้งแต่เด็ก 
เพราะมักจะตั้งคำถามเสมอว่าระบบเบื้องหลังของเกมถูกสร้างและทำงานอย่างไร

- พอได้เข้ามาเรียนในระดับมหาวิทยาลัย จึงได้เปลี่ยนความสนใจนั้นให้กลายเป็นทักษะการเขียนโปรแกรมจริง ทั้งภาษา Python, C, C++ และ Java 
โดยโปรเจกต์ล่าสุดที่ได้ทำคือการพัฒนา Ray Tracer เพื่อจำลองภาพหลุมดำด้วย Python OOP จากเดิมที่ระบบฉายรังสีแสงเป็นเส้นตรง 
ผมได้เขียนเพิ่ม Logic เพื่อจำลองการเบี่ยงเบนของเส้นแสงด้วยการยิงแสงใหม่จากจุดที่เป็น Event Horizon 
ประสบการณ์นี้นอกจากจะทำให้เห็นภาพการออกแบบ Object-Oriented อย่างชัดเจนแล้ว ยังฝึกทักษะสำคัญอย่างการอ่านและต่อยอด Codebase เดิมด้วยครับ

- สำหรับการฝึกงานครั้งนี้ ผมตั้งใจจะนำทักษะด้านต่างๆที่ผมได้ฝึกมา ไปช่วยเสริมงานของทีมอย่างเต็มที่ครับ
